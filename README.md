# Novel Site

Готовый сайт для новеллы: список глав, чтение по главам, админка, загрузка аудио и автоматическое плавное переключение фоновой музыки по секциям текста.

## Локальный запуск

Требуется Node.js 20+.

```bash
npm install
cp .env.example .env
npm start
```

Откройте `http://localhost:3000`.
Админка: `http://localhost:3000/admin/login`.

## Переменные окружения

- `ADMIN_PASSWORD` — пароль автора.
- `SESSION_SECRET` — длинная случайная строка для подписи cookie.
- `DATA_DIR` — каталог для SQLite и загруженных аудиофайлов. В Railway используйте `/data`.

## Railway

1. Загрузите проект в GitHub.
2. В Railway создайте новый проект из GitHub repo.
3. Добавьте Volume и смонтируйте его в `/data`.
4. Задайте `ADMIN_PASSWORD`, `SESSION_SECRET`, `DATA_DIR=/data`.
5. Railway определит `Dockerfile` и запустит приложение.

SQLite-файл и музыка будут лежать в volume.

## Как работает музыка

Каждая секция главы имеет `Музыка URL` и `Плавность перехода`.
Когда читатель доходит до секции, IntersectionObserver выбирает её трек. Второй `<audio>`-элемент заранее запускает новый трек, после чего громкость старого плавно снижается, а нового — повышается. Трек зациклен (`loop`) и продолжает играть до переключения на другую секцию или до секции без музыки.

Браузеры могут запрещать автозапуск со звуком до первого взаимодействия пользователя. На странице есть кнопка ▶/❚❚ для запуска музыки; после первого жеста переходы работают автоматически.
